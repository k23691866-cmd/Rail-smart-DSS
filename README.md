# 🚆 RailSmart DSS

A professional Railway Decision Support System built with Flask.

## ✨ Features

- 🔐 Secure authentication (Bcrypt + Flask-Login)
- 🎫 Ticket booking with live train info & fare calculation
- 🔍 PNR status lookup
- ❌ Ticket cancellation with seat restoration
- 📊 Personal dashboard with KPIs
- 🛡️ Admin panel (manage trains, users, bookings)
- 📈 Reports & revenue analytics
- 📱 Responsive, modern UI
